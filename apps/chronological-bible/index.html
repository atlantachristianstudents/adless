About this reader

Recovery Version Scripture, downloaded on first use from the shared RcV text file and stored in IndexedDB for offline reading, arranged in a chronological sequence adapted from Edward Reese’s chronological Bible, with some changes to passage placement.

Chronological placement is an editorial interpretation. Passages from different books are interwoven; the reference beside each passage identifies its original location.

All 31,102 references in the local order file are matched. RcV’s additional Revelation 12:18 follows 12:17, for 31,103 verses total. This reader contains Scripture text, without study notes.

Your position, bookmarks, and appearance stay in this browser. Click a verse or press Space to toggle its highlight. Use ↑ / ↓ or k / j to move it, ← / → or h / l for readings, m to save a verse, / to search, and Escape to close panels.

Chronological Bible is part of the ACS Web Apps project.
